## Summary

Run the initial Prisma migration (`init_base_identity_tenant_models`) to create the `users`, `tenants`, and `tenant_memberships` tables in the local PostgreSQL database. Add a `prisma:migrate:status` script and `db:status` root script for migration status checking. Create `docs/development.md` as the canonical local data layer developer reference.

This is a pure infrastructure task: no new Prisma models, no business logic, no API endpoints, no seed data.

## Local Reset Instructions (DESTRUCTIVE)

> ⚠️ **DESTRUCTIVE — LOCAL DEVELOPMENT ONLY**  
> These commands delete all data. Never run against a production database.  
> Verify `DATABASE_URL` points to `localhost` before proceeding.

**Option 1 — Prisma reset (re-applies all migrations)**:
```powershell
pnpm --filter @leaseKo/api exec prisma migrate reset
# Prompts for confirmation. Type 'y' to proceed.
```

**Option 2 — Docker volume reset (full wipe)**:
```powershell
pnpm db:reset    # docker compose down -v — removes volumes
pnpm db:up       # restart container
pnpm db:migrate  # re-apply migration
```
