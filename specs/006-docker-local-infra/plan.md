# Implementation Plan: Local Infrastructure — Docker, PostgreSQL, Redis

**Branch**: `006-docker-local-infra` | **Date**: 2026-05-02 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/006-docker-local-infra/spec.md`

## Summary

Set up and complete the local Docker-based infrastructure for the LeaseKo monorepo. PostgreSQL 16 and Redis 7 run as Docker containers managed by `infra/docker-compose.yml`. The NestJS backend validates `DATABASE_URL` and `REDIS_URL` at startup and fails fast if either is absent. Most infrastructure scaffolding already exists; this feature's work is targeted: pin the unpinned `adminer:latest` image tag, add three missing root scripts (`db:logs`, `db:ps`, `db:reset`), and expand README.md with a comprehensive local infrastructure section.
